## 4. Discord 웹후크 알림 구현

### 요청 내용

`git push` 시 커밋 내역과 메모를 Discord로 알림 전송

### 구현 방식

`pre-push` git 훅 → `scripts/discord-push-notify.sh` 자동 실행

### 생성/수정 파일

| 파일 | 내용 |
|------|------|
| `scripts/discord-push-notify.sh` | Discord 웹후크 알림 스크립트 (jq 기반 JSON 생성) |
| `scripts/install-hooks.sh` | `.git/hooks/pre-push` 자동 설치 스크립트 |
| `.env.example` | `DISCORD_WEBHOOK_URL=` 항목 추가 |
| `.env.local` | `DISCORD_WEBHOOK_URL` 실제 값 입력 |

### 알림 포함 내용

- 저장소 이름, 브랜치
- 작성자 (git config user.name)
- 최근 커밋 5개 (oneline)
- 선택적 메모 (`PUSH_MEMO` 환경변수)

### 사용법

```bash
# 훅 설치 (최초 1회)
bash scripts/install-hooks.sh

# 이후 git push 할 때마다 자동 알림
git push

# 메모 포함
PUSH_MEMO="홈 피드 API 연동 완료" git push

# 알림만 테스트 (push 없이)
bash scripts/discord-push-notify.sh "테스트 메모"
```

### 트러블슈팅

- 1차 구현: `printf` 기반 JSON → 줄바꿈/특수문자로 인해 전송 실패 (HTTP 400)
- 수정: `jq` 기반으로 재작성 → 전송 성공 확인 (HTTP 204)

## 5. GitHub 리모트 URL 수정

### 문제

`git push` 결과에서 다음 경고 확인:
```
remote: This repository moved. Please use the new location:
remote:   https://github.com/hyeonseok555/newron-web.git
```

기존 리모트가 `newron_web` (언더스코어)으로 설정되어 있었음

### 수정

```bash
git remote set-url origin https://github.com/hyeonseok555/newron-web.git
```

- 변경 후: `https://github.com/hyeonseok555/newron-web.git` (하이픈) 정상 반영
