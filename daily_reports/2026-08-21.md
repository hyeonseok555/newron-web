## 3. 신규 페이지 구현

`app/(main)/` 그룹 하위에 로그인 불필요·정적 프리렌더링되는 4개 페이지 추가:

| 경로 | 파일 | 내용 |
|---|---|---|
| `/support` | `app/(main)/support/page.tsx` | 운영주체·이메일·문의시간, 정책 페이지 링크, 앱 정보 |
| `/privacy` | `app/(main)/privacy/page.tsx` | 개인정보처리방침 (수집항목: Google 로그인 이메일/이름, 게스트 UUID, 북마크·기록·검색어 / 목적·보유기간·제3자제공·위탁(Google)·이용자 권리·책임자) |
| `/account-deletion` | `app/(main)/account-deletion/page.tsx` | 앱 내 탈퇴 절차 안내, 삭제되는 정보 목록, 이메일 대체 요청 경로 |
| `/terms` | `app/(main)/terms/page.tsx` | 이용약관 (목적/정의/효력·변경/서비스 제공/회원가입·탈퇴/이용자 의무/콘텐츠·저작권/면책/준거법/문의처, 10개 조항) |

### 푸터 연동 (`app/(main)/layout.tsx`)

- 기존 "빠른 링크" 영역의 더미(`href="#"`) 항목을 위 4개 페이지 실제 링크로 교체
- "문의 및 연결" 영역의 아이콘 버튼 중 이메일 아이콘을 `mailto:juing95@gmail.com`로 연결, 사용하지 않는 더미 아이콘(RSS, 공유) 제거
- 로그인 여부와 무관하게 모든 페이지 하단에 항상 노출되도록 하여 "게스트 상태에서 심사자가 못 찾는" 리스크 방지
