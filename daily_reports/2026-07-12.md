## 4. 실서버 API 명세 불일치 발견 및 수정

개발 서버로 실제 프록시 호출을 검증하는 과정에서 `daily_reports/docs/web-design-spec.md` 명세와 실제 개인화 서버(포트 7000) 동작이 다른 부분을 발견하여 수정함.

| 항목 | 명세서 | 실서버 (openapi.json 확인) | 조치 |
|---|---|---|---|
| 추천 뉴스 | `POST /api/v1/recommend/` (body: user_id, limit) | `GET /api/v1/recommend/{user_id}?limit=` | `lib/api/news.ts`의 `fetchRecommendedNews`를 GET 방식으로 수정 |
| 북마크 목록 조회 | `PersResponse` 포맷 (`{code, message, result}`) | `MainResponse` 포맷 (`{status, data}`) | `fetchBookmarks`가 `res.data.data`를 읽도록 수정 |

### 부수 발견: Next.js 트레일링 슬래시 리다이렉트 문제

- `POST /api/proxy/pers/api/v1/recommend/`처럼 끝에 `/`가 붙은 프록시 요청을 Next.js가 308로 자동 리다이렉트하면서 슬래시를 제거 → FastAPI 백엔드가 슬래시 유무로 라우트를 구분하는 경우 404 발생
- `next.config.ts`에 `skipTrailingSlashRedirect: true` 추가하여 프록시가 원본 경로를 그대로 백엔드에 전달하도록 수정
